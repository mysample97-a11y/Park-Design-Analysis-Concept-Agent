# Landing page videos

Place three files here. The landing page references them by these exact names:

| File | Used for |
|---|---|
| `portal.mp4` | Fullscreen backdrop behind the scrolling stages (loops continuously) |
| `hologram.mp4` | Circular animation at the centre of the instrument ring |
| `timelapse.mp4` | Construction timelapse in the right-hand panel (loops continuously) |

If a file is missing the page still works — that panel simply renders dark. Nothing breaks.

**Keep them small.** These load on first visit, so anything above roughly 5 MB each will make
the landing feel slow on a phone. Compress before committing; GitHub also refuses files over
100 MB outright.
